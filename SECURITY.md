# Security Policy

## Supported Versions

Only the latest `main` branch is supported with security updates.

## Reporting a Vulnerability

Report vulnerabilities privately by email:

- `contato.jrod@gmail.com`

Please include:

- Affected repository (`tabulav0dev-new`)
- Steps to reproduce
- Impact assessment
- Suggested fix (if available)

## Response Targets

- Initial response: up to 72 hours
- Triage decision: up to 7 business days
- Fix timeline: depends on severity and deployment risk

Do not open public GitHub issues for security reports.

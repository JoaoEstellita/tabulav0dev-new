# Match (Rede → Tinder Astrológico) — Fase 1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Estender a Rede com perfil rico (fotos/tags/bio), gate de assinante+trial, sub-menu (Descobrir/Match/Perfil), renomear a aba para "Match 💘" e um guia carrossel de onboarding — sem tocar o baralho/swipe (Fase 2).

**Architecture:** Backend estende o handler `discovery.js` (novas ações `set-profile`; `buildPublicProfile` deriva `age`/`element`; gate `isPremium` em todas as ações). Frontend reorganiza `NetworkScreen` em 3 seções, adiciona a tela de edição de Perfil (upload de fotos via Storage, tags, bio), o paywall, o carrossel de intro e o rename da aba. Dados novos moram em `discoveryProfiles` (catch-all `if false` — só backend); zero mudança de regras de segurança.

**Tech Stack:** Node (backend Vercel, Firebase Admin), React Native + TypeScript + Expo, Firebase Storage, Vitest (frontend) / node asserts (backend), i18n `appI18n.ts` (4 idiomas).

**Spec:** [docs/superpowers/specs/2026-08-28-rede-tinder-astrologico-design.md](../specs/2026-08-28-rede-tinder-astrologico-design.md)

## Global Constraints

- **Privacidade:** nunca publicar data/hora/local de nascimento em `discoveryProfiles`; só idade inteira (`age`). `matchPositions` nunca sai ao cliente. Fotos só do próprio uid.
- **Gate:** usar `entitlements(uid).isPremium` (admin OU assinatura ativa OU trial não-vencido) — NÃO `isSubscriber`.
- **Regras Firestore:** NÃO alterar. `discoveryProfiles`/`swipes`/`connections` já são `if false` (catch-all) — só backend Admin.
- **i18n:** toda string exibida existe nos 4 idiomas (pt-BR, en-US, es-ES, it-IT). Regra: en-US sem "will"; es-ES sem tildes; it-IT sem acentos.
- **Commits:** Conventional Commits, `--no-verify`, footer `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`. Backend NÃO auto-deploya (`npm run deploy`); frontend auto-deploya.
- **Limites de dados:** fotos ≤ 4 (1 capa + 3); interesses ≤ 10 tags; bio ≤ 300 chars.

const SIGN_ELEMENT = {
  'Áries': 'fogo', 'Leão': 'fogo', 'Sagitário': 'fogo',

  'Gêmeos': 'ar', 'Libra': 'ar', 'Aquário': 'ar',
  'Câncer': 'agua', 'Escorpião': 'agua', 'Peixes': 'agua',
}
function ageFromBirthDate(birthDate) {
  if (!birthDate || typeof birthDate !== 'string') return null
  const [y, m, d] = birthDate.split('-').map(Number)
  if (!y || !m || !d) return null
  const now = new Date()
  let age = now.getUTCFullYear() - y
  const beforeBirthday = now.getUTCMonth() + 1 < m || (now.getUTCMonth() + 1 === m && now.getUTCDate() < d)
  if (beforeBirthday) age -= 1
  return age >= 0 && age < 120 ? age : null
}

- [ ] **Step 3: Implementar** `profileInput.js`:

```js
'use strict'
const slug = (s) => String(s || '').toLowerCase().normalize('NFD').replace(/[̀-ͯ]/g, '').replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '')
function sanitizeProfileInput({ photos, interests, bio } = {}) {
  const ph = Array.isArray(photos) ? photos.filter((u) => typeof u === 'string' && /^https?:\/\//.test(u)).slice(0, 4) : []
  const seen = new Set()
  const it = Array.isArray(interests) ? interests.map(slug).filter((s) => s && !seen.has(s) && seen.add(s)).slice(0, 10) : []
  let b = String(bio || '').replace(/[<>]/g, '').replace(/https?:\/\/\S+/g, '').replace(/\s+/g, ' ').trim().slice(0, 300)
  return { photos: ph, interests: it, bio: b }
}
module.exports = { sanitizeProfileInput, slug }
```

🚨 REGRAS DE EMERGÊNCIA PARA FIREBASE 🚨

COPIE E COLE ESTAS REGRAS NO FIREBASE CONSOLE:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // REGRAS TEMPORÁRIAS ULTRA-PERMISSIVAS
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

📋 COMO APLICAR:
1. Abra Firebase Console → Seu projeto
2. Firestore Database → Rules
3. Cole as regras acima
4. Clique em "Publish"

⚠️ IMPORTANTE: Estas são regras temporárias para debug!
